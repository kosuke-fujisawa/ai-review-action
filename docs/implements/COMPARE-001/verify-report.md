## 延長タイムアウト診断

一時コピーだけAPIタイムアウトを300秒へ延長すると、現行Actionの陽性ケースは89.1秒で完了した。ただし既知3件はすべて未検出で、別の2件を指摘した。

標準実行で完了した陰性ケースと合わせた診断上の精度は、現行Actionも `TP=0 / FP=4 / FN=3` である。したがって、標準タイムアウトだけを直しても今回の正解データに対する検出精度は改善しない。

## 判定

この4ケースだけでは一般的な優劣は断定できないが、少なくとも次を確認した。

- PR-Agentは現行Actionより完走率と速度が良い。
- 両者とも既知3件を検出できず、現在のプロンプト・モデル構成では精度が不足している。
- 現行Actionの証拠ゲートは候補1件を棄却できたが、採用された誤検知も残った。
- 追加の変異パイロットではfilterが正解3件をすべて棄却し、誤検知1件を通過させた。
- PR-Agentへの単純置換も、現行Actionを汎用レビュアーとしてそのまま公開することも、この実測からは支持できない。

詳細な判断は `comparison-report.md` と `filter-effectiveness-report.md` を参照する。
