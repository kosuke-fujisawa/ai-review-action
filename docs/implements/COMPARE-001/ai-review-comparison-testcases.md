# AIレビュー基盤比較 テストケース

## 正常系

1. 🟢 **全既知問題を重複なく検出する**
   - 3件の既知問題に3件の指摘が一対一で一致する。
   - TP=3、FP=0、FN=0、precision=1、recall=1、F1=1となる。

2. 🟢 **問題なしケースで指摘しない**
   - 既知問題0件、指摘0件のケースを完了する。
   - FPを増やさず、完了ケースとして数える。

3. 🟢 **Markdownレポートを生成する**
   - エンジン名、TP/FP/FN、precision/recall/F1、完了状況を含む。

## 異常系

4. 🟢 **存在しない既知問題IDへの一致を拒否する**
   - 結果がケース定義にないIDを参照した場合、入力エラーにする。

5. 🟢 **未定義ケースの実行結果を拒否する**
   - manifestにないcaseIdを含む結果は入力エラーにする。

## 境界値

6. 🟢 **重複検出をノイズとして数える**
   - 同じ既知問題へ2件が一致した場合、最初をTP、2件目をFPとする。

7. 🟢 **未一致指摘をFPとして数える**
   - `matchedExpectedIds=[]` の指摘をFPとする。

8. 🟢 **blocked実行を精度計算から除外する**
   - 未実行ケース数へ加え、比較可能=falseとする。

9. 🟢 **結果が存在しないケースを未完了として扱う**
   - 全ケースの結果が揃わなければ比較可能=falseとする。

## 技術

- 言語: JavaScript (ES Modules)
- テスト: Node.js組み込みtest runner
- 実行: `node --test benchmark/*.test.mjs`
