# AIレビュー基盤比較 要件

## 概要

- 🟢 対象は現行の `ai-review-action` と PR-Agent v0.35.0。
- 🟢 同じGit差分・同じOpenAIモデルを入力し、検出精度、ノイズ、時間、API使用量を比較する。
- 🟢 外部PRへコメントを投稿せず、ローカル成果物だけを評価する。
- 🟡 最初の正解データは、PR #4で実際に検出・修正された3件と、既知問題のない修正コミットを使用する。

## 入力

### ベンチマーク定義

- ケースID
- 比較対象のbase/headコミット
- 既知問題のID、説明、対象ファイル
- 根拠となるレビューコメントまたはテスト

### 実行結果

- エンジン名
- ケースID
- 実行状態（completed / blocked / failed）
- 所要時間
- 入出力トークン数と費用（取得できる場合）
- 指摘一覧
- 各指摘が一致する既知問題ID（人手で判定）

## 出力

- エンジン別のTP、FP、FN
- precision、recall、F1
- 実行済みケース数と未実行ケース数
- 平均所要時間
- API使用量・費用（取得できた実行のみ）
- 比較可能かどうかの判定
- Markdown形式の比較レポート

## 判定規則

- 既知問題を最初に捉えた指摘をTPとする。
- 同じ既知問題への重複指摘はFPとする。
- 既知問題に一致しない指摘はFPとする。
- どの指摘にも一致しなかった既知問題はFNとする。
- `blocked` / `failed` の実行は精度計算へ混ぜず、未完了として明示する。
- 全エンジンが全ケースを完了するまで、採用判断を確定しない。

## 制約

- 🟢 OpenAI APIキーをリポジトリへ保存しない。
- 🟢 PR-Agentは固定版v0.35.0を隔離環境で使う。
- 🟢 PR-AgentはLocalGitProviderを使い、GitHubへ投稿しない。
- 🟢 両エンジンで `gpt-5-mini` を使用する。
- 🟢 正解ラベルはモデル自身に採点させず、人が根拠を確認して割り当てる。
- 🟡 APIキーがない環境では、評価基盤、ケース準備、非投稿実行確認までを完了し、モデル実測をblockedとして残す。

## 受け入れ条件

- 評価計算の正常系、重複指摘、未一致指摘、未実行ケース、無効な既知問題IDを自動テストする。
- 既存テストを壊さない。
- PR-Agent v0.35.0のCLI起動とLocalGitProviderの利用方法を確認する。
- 比較未完了を完全な比較結果として扱わない。
